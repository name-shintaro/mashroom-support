| ファイル | 用途 |
|----------|------|
| `index.html` | アプリ説明・使い方・サポート（ASC サポートURL） |
| `spec.html` | 製品仕様（公式 Ver 1.0 / Build 2、印刷可） |

## 更新の流れ

1. 本リポジトリ `docs/support/` を編集
2. 内容を `mashroom-support` リポジトリ直下へコピーして push（Pages は `main` / root）
3. 数分待って公開URLを確認
